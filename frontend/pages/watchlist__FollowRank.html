Neko | The Fastest Sui Meme Trading Terminal

Neko is a MEME token trading platform supporting Sui — covering new token monitoring, security auditing, holder analysis, smart money copy trading, wallet P&L analytics, and automated trade execution, widely used for early-stage on-chain project discovery and quantitative trading.

Core Features

  1. Real-Time New Token Monitoring

    Continuously scans Sui launchpad tokens with filters for market cap, volume, and creation time — helping users enter positions at early low-cap stages.

  2. Live Trending Token Rankings

    Leaderboard updated every minute based on buy/sell count, trading volume, price change, and holder growth — reflecting real-time market momentum and capital flow.

  3. Token Holder Structure Analysis

    Real-time calculation of four key metrics: insider/rat wallet ratio, bundle buy ratio, DEV holdings %, and Top 10 wallet concentration.

  4. Automated Token Security Audit

    Auto-checks every token for: LP burned status, honeypot detection, contract renounced status, and mintable flag.

  5. Smart Money Copy Trading

    Identifies high-win-rate wallets on-chain and enables one-click copy trading that automatically mirrors their buy/sell actions and position sizing.

  6. KOL & Wallet Tracker with Real-Time Alerts

    Custom watchlist with real-time push notifications for every on-chain event — buys, sells, position adds, and full exits — from tracked wallets and KOLs.

  7. Zero-Latency Trading & Automated Strategies

    Zero-latency on-chain trade execution with Take Profit, Stop Loss, Trailing Take Profit / Trailing Stop Loss, and multi-wallet batch order support.

  8. Wallet P&L Analytics

    Enter any wallet address to instantly generate: realized/unrealized PnL, win rate and risk/reward ratio, current holdings valuation, full trade history, and developer wallet token creation records with all-time high (ATH) market cap per token.

  9. Trading Data API & AI-Native Skills

    Five structured API categories — token data, wallet data, market data, trade execution, and signal tracking — packaged as standardized AI Skills directly callable by Claude, GPT, and other AI Agents via natural language for on-chain data queries and trade execution.
